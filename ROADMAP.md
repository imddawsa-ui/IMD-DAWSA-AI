# IMD DAWSA AI — Development roadmap

## 0.1 Local assistant foundation
FastAPI service, Arabic web UI, Ollama chat, SQLite history and health checks. Target: Windows 11, 8 GB RAM, CPU-only.

## 0.2 Personal assistant
Conversation history retrieval, user-controlled memory, streaming, cancellation, export and deletion controls.

## 0.3 Multimodal tools
Optional speech-to-text, text-to-speech, image understanding and validated file upload.

## 0.4 Accounts and cloud mode
Email verification, optional cloud model adapters with consent/cost controls, PostgreSQL migrations and backups.

## 0.5 Super App modules
Profiles, posts, feed, messaging, groups, notifications, marketplace, business pages, learning, creator tools, moderation and admin audit logs.

## 0.6 Integrations and production
Official OAuth/API integrations, background jobs, object storage, observability, rate limits and deployment hardening.

A milestone is complete only after implementation, tests and a real deployment check. This project integrates existing models; it does not train a frontier model from scratch.
